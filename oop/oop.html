What is OOP?

Object-Oriented Programming explained simply.

Object-Oriented Programming

OOP stands for Object-Oriented Programming.

English: OOP is a programming style where code is organized around objects that contain data and behavior.
Roman Urdu: OOP ek programming style hai jisme code ko objects ki form mein organize kiya jata hai, aur objects ke andar data aur functions hote hain.

4 Pillars of OOP

The four main concepts of Object-Oriented Programming.

01

Encapsulation

English: Bundling data and methods together.

Encapsulation means keeping related data and methods together inside an object or class and controlling access to them.

Roman Urdu: Kisi bhi related data aur methods ko ek object ya class mein rakhna Encapsulation kehlata hai 
class Student {

    constructor(name) {
        this.name = name;
    }

    study() {
        console.log("Studying...");
    }
}
02

Abstraction

English: Hiding unnecessary details.

Abstraction means hiding complex or unnecessary implementation details and showing only what is important.

Roman Urdu: Agar hum program mein user ko sirf zaroori cheezein show karwain aur baqi internal details hide kar dein, to isay Abstraction kehte hain. 
class Car {

    start() {
        console.log("Car started");
    }
}

const car = new Car();

car.start();
03

Inheritance

English: Reusing another class's features.

Inheritance allows one class to reuse properties and methods from another class.

Roman Urdu: Ek class doosri class ki properties aur methods ko reuse kar sakti hai. 
class Animal {

    eat() {
        console.log("Eating...");
    }
}

class Dog extends Animal {

    bark() {
        console.log("Woof!");
    }
}

const dog = new Dog();

dog.eat();
dog.bark();
04

Polymorphism

English: Same method, different behavior.

Polymorphism means the same method can behave differently depending on the object.

Roman Urdu: Same method different objects mein different tarah behave kar sakta hai 
class Dog {
    sound() {
        console.log("Dog barks");
    }
}

class Cat {
    sound() {
        console.log("Cat meows");
    }
}

new Dog().sound();
new Cat().sound();

Simple OOP Example

Let's understand a class, object, property and method. 

class Person {

    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    introduce() {
        console.log(
            `My name is ${this.name}`
        );
    }
}


const person1 =
    new Person("Ali", 20);


person1.introduce();
Roman Urdu: Yahan humne Person naam ki class banayi. Constructor mein name aur age properties hain, jabke introduce() ek method hai. Phir new Person() ki help se object create kiya gaya.

Class in JavaScript

Understand what a class is, why we use it and when to use it.

C

What is a Class?

A class is a blueprint or template used to create objects with similar properties and methods.

Roman Urdu: Class ek blueprint ya template hoti hai jiske through hum same structure wale multiple objects bana sakte hain.
01

Why do we use Class?

When we have multiple objects with the same properties and methods, a class helps us avoid writing the same code again and again.

Roman Urdu: Jab humein same type ke multiple objects banane hon, to class code ko repeat hone se bachati hai.
02

When to use Class?

Use a class when multiple objects share the same structure and behavior.

Roman Urdu: Jab multiple objects ki properties aur methods same hon, tab class useful hoti hai.
Example

Student Class

One class can be used to create multiple student objects. 

                        class Student {

                                constructor(name, age, course) {
                                    this.name = name;
                                    this.age = age;
                                    this.course = course;
                                }

                                introduce() {
                                    console.log(`My name is ${this.name}`);
                                }
                            }

                        const student1 =
                        new Student("Ali", 20, "JavaScript");
                        const student2 =
                        new Student("Sara", 22, "React");
                        const student3 =
                        new Student("Ahmed", 21, "Node.js");
Roman Urdu: Humne ek Student class banayi. Is class mein name, age aur course properties hain aur introduce() method hai. Phir isi ek class se humne student1, student2 aur student3 objects create kiye.
